# Validation

There is no labelled ground truth for wallet clusters. This is a hand review of a reproducible random sample.

Sample generated by `pnpm --filter @nuno/metrics validation 42` at mainnet block 111,709,445: 20 flagged links (of 90, across 1 entities) and 10 unflagged buyer wallets (of 19).

**Verdict key.** Flagged link: `TP` = the evidence shows common control, `FP` = plausibly independent (e.g. both funded by an exchange), `?` = can't tell. Unflagged wallet: `TN` = no sign of a link to another sampled/known operator, `FN` = a link Nuno missed.

**Observed precision** = TP / (TP + FP) on flagged links. Reported in the README only for this sample.
